🔌 Connecting Your Local AI System

Because this harness runs via a live web app, your browser security blocks requests to local software unless your system permits cross-origin communication. Follow these quick steps to bring your own local model:

Step 1: Install & Download a Model Locally
Download Ollama or LM Studio, then pull a public open-source model through your terminal:
ollama pull llama3
Step 2: Enable Browser Access (CORS Fix)
Since web browsers protect local ports, run this command in your terminal so this hosted web app can securely communicate with your computer's local AI engine:
launchctl setenv OLLAMA_ORIGINS "*" (Mac) or set environment variable OLLAMA_ORIGINS="*" (Windows/Linux), then restart your local app.
