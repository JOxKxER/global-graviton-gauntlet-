📖 Master Setup & Troubleshooting Guide (Zero to Air-Gapped)

If you are seeing a "Failed to fetch" error in your console, it means your browser cannot talk to your local computer engine yet. Follow these precise steps to establish the handshake:

Step 1: Download & Install Ollama

Ollama is the local AI engine that runs models on your hardware. If you haven't installed it yet, download it directly from the official source:

🔗 Official Ollama Download Website (ollama.com)

Step 2: Pull a Code & Reasoning Model

Open your computer's terminal (Command Prompt/PowerShell on Windows, or Terminal on Mac) and type this exact command to download a lightweight, high-performance model:

ollama pull qwen2.5-coder:latest

Step 3: Fix "Failed to fetch" (Configure CORS & Network Host)

By default, Ollama blocks external web browsers and network traffic for security. You must configure it to accept local connections:

  • On Windows:
    1. Completely quit Ollama from your system tray (bottom-right taskbar near the clock).
    2. Open Windows Start, search for Environment Variables, and click "Edit the system environment variables".
    3. Click the Environment Variables... button, then click New... under User variables.
    4. Set Variable name to OLLAMA_HOST and value to 0.0.0.0:11434. Click New again, set Variable name to OLLAMA_ORIGINS and value to *. Click OK and restart Ollama.
  • On Mac / Linux: Open Terminal and run:
    launchctl setenv OLLAMA_HOST "0.0.0.0:11434"
    launchctl setenv OLLAMA_ORIGINS "*"
    Then restart the Ollama app from your menu bar.
