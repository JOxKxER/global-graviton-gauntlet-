📖 Beginner's Step-by-Step Guide: How to Set Up & Connect Your Local AI

Because this platform operates 100% locally with zero cloud servers, your computer needs a local AI engine installed. Follow these exact instructions:

Step 1: Download & Install Ollama (Free Local AI Engine)
Go to ollama.com, download the installer for your computer (Windows, Mac, or Linux), and run it to install Ollama.
Step 2: How to Open Your Computer's Terminal & Download a Model
• Windows: Press the Windows Key on your keyboard, type cmd or PowerShell, and press Enter.
• Mac: Press Cmd + Spacebar, type Terminal, and press Enter.
Once the black terminal window opens, type this exact command and press Enter to download a lightweight AI model:
ollama pull llama3.2:3b
Step 3: Allow Browser Connection (CORS Fix)
Web browsers protect local ports for security. To allow this website to communicate with your computer's local AI:
• Mac / Linux: In your terminal, type export OLLAMA_ORIGINS="*" and press Enter before running Ollama.
• Windows: Search your Windows menu for "Edit the system environment variables", click Environment Variables, click New under User variables, enter Variable name: OLLAMA_ORIGINS and Variable value: *, then click OK and restart Ollama.
📱 Instructions for Mobile & Tablet Users:
Smartphones and tablets cannot run local desktop AI runtimes like Ollama natively. To use this web app on mobile:
  1. Ensure Ollama is running on your desktop/laptop computer on the same Wi-Fi network.
  2. In the Endpoint URL box below, replace localhost with your computer's local Wi-Fi IP address (e.g., http://192.168.1.50:11434/...).
  3. For easiest offline execution anywhere, download our official app package from the button at the top of the page!
