📖 Complete Setup Guide: Downloading & Connecting Your Local AI

Because this sovereign platform operates 100% locally with zero cloud dependencies, you need an open-source local LLM installed on your system. Follow these simple steps to get set up:

Step 1: Download & Install a Local LLM Runtime
Download and install Ollama (compatible with Windows, Mac, and Linux) or LM Studio. Ollama is recommended for lightweight local execution.
Step 2: Pull Your Preferred Open-Source Model
Open your computer's terminal (Command Prompt, Terminal, or PowerShell) and download a fast local model by running:
ollama pull llama3.2:3b (or another model like llama3 or mistral).
Step 3: Enable Local Browser Access (CORS Configuration)
Web browsers block web pages from communicating with local software unless permitted. To allow this site to talk to your local model:
• Mac / Linux (Terminal): Run export OLLAMA_ORIGINS="*" before launching Ollama, or set it in your system environment variables.
• Windows (System Environment Variables): Add a new user or system environment variable named OLLAMA_ORIGINS with the value *, then restart Ollama.
Step 4: Verify & Execute
Ensure your local server is running (usually at http://localhost:11434), check the connection indicator below, and start executing sovereign synthetic inference offline!
